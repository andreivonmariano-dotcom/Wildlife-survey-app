# v0.14.1 Station Workflow and GPS Checklist Regression

## Project-first setup
- Home includes Projects, Bird Survey, Herpetofauna Survey, Mammal Survey and Custom Survey.
- Project manager has a Create Project button and existing station list, but no general Add Sampling Station button.
- Tap Bird Survey. Confirm a project selector and route design fields, with NO station-entry field.
- Select 2 km route and 250 m point spacing. Confirm preview reports 9 planned stations.
- From survey setup, create a new project. On return, confirm it appears as a project choice without losing the selected method or route length.
- Start survey. Check that stations exist with permanent distinct IDs and blank GPS before arrival.
- Start Point 1, save a bird observation and finish that point. Point 2 button should appear.
- Type an unsaved observation, press Finish Point, choose Clear Draft. Confirm the app returns to **planned Point 2** rather than an old station picker.
- From Recent Surveys, confirm card shows project, survey design and survey status, not "No station".
- Repeat for generic mammal and herpetofauna station visits. The first choice must Generate Station at Current Site. Existing stations should be available only for deliberate repeat visits.
- Verify old point-count survey history and station links still work.

## Fresh phone location checklist lookup
- With phone GPS ON, press Suggest checklist using current GPS. Confirm fine-location permission prompt if not previously granted.
- Confirm the screen says it is collecting a **new** GPS fix, not reading station coordinates.
- Reject location permission and confirm a manual region remains usable.
- Turn off phone GPS and confirm the app prompts to enable location or choose manually.
- With a good GPS fix away from administrative boundaries, confirm province and accuracy are displayed, then accept the proposed island-group suggestion.
- Reject the confirmation dialog and verify the manual selection remains.
- Use a weak fix (>150 m uncertainty), near-boundary fix, or no fix within 25 seconds. The app should not apply a GPS-based geographic label.
- Accept one suggestion, then run another lookup that fails. Confirm the former detected province is not silently reused.
- Confirm no network connection is needed and no location is uploaded.
- Check the exported geographic_selection_method value is fresh_phone_gps_polygon_confirmed only after explicit confirmation.

## No scientific mislabeling
- After generating stations, edit a site's latitude or longitude in Projects. Confirm its old GPS accuracy is cleared in sites.csv.
- Confirm point_counts.csv maintains original GPS snapshot captured when the count started.
- Verify manual checklist choice still allows rare/out-of-region taxa to be recorded.
- A manually selected island group should not be displayed as a GPS-confirmed province.
- Check Not Counted, Complete and Incomplete survey outcomes, archived observations and analytical filters.
