### 2026-11-07 | PHLibrary Discovery Rarity model and concise species-card layout | Owner-approved reference format and scoring design

- Adopt PHLibrary educational reference **one natural paragraph per species**, preserving available original identification, regional-distribution, habitat, ecology, and other species-specific scientific prose and in-text citations. Show IUCN/DENR category from the dated source checklist, if available, within each account. Shift exact full species-level source references to the central bibliography, retaining bibliographic provenance.
- Place **small labelled icons/badges** below each species heading for source-supported endemism, occurrence type, **IUCN global status**, and **PHLibrary Discovery Rarity**. The reader-facing guide should show a rarity tier **without** a numerical score or provisional numeric annotation. Keep scoring numbers, inputs and evidence uncertainty in a companion downloadable Excel workbook, with a reproducible app data model for future import.
- **Five owner-selected rarity tiers:** Common (0–19.9), Uncommon (20–39.9), Rare (40–59.9), Exceptionally rare (60–79.9), Legendary (80–100). Weights: **D geographic listing breadth 40%, C IUCN status 30%, H habitat breadth proxy 25%, S research scarcity 5%**. Each sub-score is 0–4. `100*(40D+30C+25H+5S)/(4*100)` when all four scores are available. Source checklist has no comparable literature-study counts; an interim 3-factor model may use `100*(40D+30C+25H)/(4*95)`, explicitly labelled **provisional**. If D/C/H cannot be supported, **do not invent values or rank**. Data Deficient/Not Evaluated/not listed do not map to score 4.
- **Critical interpretation:** This is an **illustrative educational composite index**, **not measured encounter frequency, local abundance, population size, IUCN threat probability, or a validated scientific rarity metric**. IUCN contributes as a separate threat-related component and must remain visibly distinct as its own badge. Automatically inferred D and H scores from the general checklist are low-confidence proxies, not verified niche breadth or geographic range. Country-only `Philippines` distributions do not prove core-island breadth. A species's research scarcity cannot be inferred from the length of its description or a casual search result.
- **Do not infer narrower Mindanao Island or Greater Mindanao PAIC endemicity from absence of other named islands in a broad checklist string.** Mark Philippine endemic only when explicitly source-labelled; narrower tags require **positive source evidence**, not an incomplete island enumeration. Existing scope/taxon contradictions remain flagged and unrated. `Pithecophaga jefferyi` illustrated why: the checklist omitted Luzon but the Philippine Eagle Foundation confirms Luzon, Samar, Leyte, Mindanao (https://www.philippineeagle.org/biology/). Keep the source string, flag and withhold its modeled geographic score rather than fabricate certainty.
- Every future-app record should separately store taxon/name crosswalk, input scores, model version, composite score, visible tier, provenance and confidence. **This decision does not implement or validate any app code, database, bundle or APK.** The model is adjustable and not a fixed science authority.
