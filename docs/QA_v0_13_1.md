# v0.13.1 regression QA

## Crash reproduction
- Start Bird Survey with manual Mindanao selection and no GPS-derived province. On v0.13.0 this could crash while showing geographic species suggestions. v0.13.1 should display the species picker.
- Repeat with All Philippines, Visayas, Luzon, Palawan, Mindoro, Sulu, and Other.
- Start a Herpetofauna survey and a Mammal survey without province suggestions.
- Test province suggestions from a saved station and reopen the recording screen. Ensure province label is shown only when recorded.
- Resume an existing v0.13 active survey created without administrative province data.
- Check that incomplete or absent administrative metadata does not erase saved observations.

## Automatic project IDs
- Create a new project with only a project name. Verify ID begins PRJ- and has 12 hexadecimal characters after the hyphen.
- Try an empty project name. The form must stay open and require a name.
- Create two projects with the same display name. They must receive distinct IDs.
- Restart the app and check the project ID remains stable.

## Automatic station IDs
- Create two stations in the same project. They must receive distinct STN- prefixed 12-character random identifiers.
- Edit a station name, habitat, coordinates, and notes. Its identifier must remain the same.
- Start a point count and use station search by name. Selecting a suggestion must place the correct permanent ID in the station entry.
- End the point count and confirm existing point counts and observations remain linked to their original station IDs.
- Existing legacy station IDs, including hand-entered names and numbers, must remain unchanged after upgrade.

## Data integrity and migration
- Export an existing v0.13 backup ZIP before installing the v0.13.1 package.
- Install over v0.13, never uninstall the previous package.
- Verify existing surveys, stations, projects, imported checklist entries, photographs and records remain available.
- Confirm a fresh bird record can be saved and exported with a manually selected geographic checklist area.
