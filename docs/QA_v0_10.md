# v0.10 Field Validation

## Timers and persistence
- Start a survey with a 10-minute bird point count and read both timers. The survey timer increases, and the station timer decreases.
- Move from Point 1 to Point 2. Confirm station timer resets and **total survey timer never resets**.
- Compare event elapsed time from UTC start/end with the exported `surveys.csv`.
- Check final 30 seconds: red pulse. After 0:00, verify **OVERTIME +00:00:01** and solid red, without auto-finish.
- Background the app, resume and confirm timers reconstruct from stored timestamps, not from an Activity-only stopwatch.
- Line transect with 120-minute target must continue tracking and allow record entry after time expiry.

## Station suggestions and repeated units
- Register four stations. Point count at the first two, then open Next Station. Unvisited stations should appear first.
- Record birds at each point and verify event ID is shared, but point_count_id differs.
- For herpetofauna VES and amphibian call visits, start one unit, finish and choose another station. Check completed visits and exported `sampling_units.csv`.
- Repeat for mammal track/sign or spotlight visits. Verify independent unit IDs and station IDs.
- End a visit early: completed flag must be 0, and the enclosing survey should not claim all units were complete.
- Keep a visit with zero detections. Check the visit row remains in exports.

## Biological observations
- Herpetofauna: record stage, microhabitat, substrate, height above ground, temperature, humidity and noise score.
- Amphibian call 0 should not generate a species detection. Positive call indexes must not automatically count individuals.
- Mammal: record track/scat/camera/acoustic evidence and equipment ID, and verify count basis isn't indistinguishable from individuals.
- For equipment checks, save verified number of devices and device-hours only when measured.

## Research exports
- Survey event duration vs unit duration: `surveys.csv` and `sampling_units.csv`.
- `occupancy_visits.csv`: per-unit visit denominators and linked positive records, no made-up species absences.
- `sdm_occurrences.csv`: observer GPS, not wildlife's precise location.
- Confirm R Distance draft still uses each point count as a distinct sample and line effort in consistent distance units.
- Compare GPS path estimate against independently measured route length before using it for survey-effort analyses.

## Release safety
- Export and archive the v0.9 ZIP before installing v0.10.
- Install as an update, not by deleting the previous app.
- Test existing v0.9 records and the non-destructive database schema upgrade.
- Verify that the GitHub APK build passes and the Release asset is attached. Android compilation is not handset validation.
